# ThachRC Website

Website cá nhân giới thiệu các modpack game của **ThachRauCau** (ThachRC): Minecraft và Stardew Valley.

## Cấu trúc trang

| Trang | Mô tả |
| --- | --- |
| `index.html` | Trang chủ: avatar, tiêu đề ThachRC, nút vào danh sách dự án |
| `projects.html` | Trang chọn game: ThachCraft (Minecraft) và Stardew Valley |
| `minecraft.html` | Trang chi tiết modpack ThachCraft |
| `stardew.html` | Trang chi tiết mods Stardew Valley Expanded |

## Tính năng

- Nền tối tím với hiệu ứng mưa pixel và scanline (`bg.js`)
- Hiệu ứng chuyển trang fade (`script.js`, `projects.js`, `minecraft.js`, `stardew.js`)
- Font pixel **Bungee** + font **Poppins**
- Nút tải modpack trỏ tới Google Drive
- Liên kết mạng xã hội: GitHub, Facebook, Discord

## Cách chạy website

Chỉ cần mở `index.html` bằng trình duyệt (hoặc dùng Live Server):

```sh
# Nếu dùng VS Code: cài extension "Live Server" rồi nhấn Go Live
```

Không cần cài đặt gì thêm, mọi thứ đều là HTML/CSS/JS tĩnh.

## Cài đặt modpack

### Minecraft – ThachCraft

1. Tải modpack tại nút **Tải xuống modpack** trên trang `minecraft.html` (file `.rar`).
2. Giải nén toàn bộ file vào thư mục `.minecraft/versions`.
3. Trong Minecraft Launcher, chọn phiên bản tương ứng và bắt đầu chơi.

ThachCraft gồm **46 mod**, **8 gói tài nguyên** và **1 shader**.

### Stardew Valley – Stardew Valley Expanded

1. Cài **SMAPI** (trang `stardew.html` có nút riêng) — bắt buộc để chạy mods.
2. Tải mods tại nút **Tải mods** (file `.rar`).
3. Giải nén thư mục `Mods` vào thư mục gốc cài đặt Stardew Valley.
4. Chạy game qua `StardewModdingAPI.exe`.

Bộ mods gồm **47 mod**, **10 gói nội dung** và **1 mod AI** (chủ yếu là Stardew Valley Expanded).

## Công dụng

- **ThachCraft**: trải nghiệm Minecraft Việt hóa với đủ mod nền tảng, tài nguyên và shader đẹp.
- **Stardew Valley Expanded**: mở rộng bản đồ, NPC, cốt truyện và giao diện cho Stardew Valley, bổ sung chữ Việt, âm thanh, hệ thống nông trại thông minh.
